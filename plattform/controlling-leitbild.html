Controlling beim CV · Modul 01

Das Controlling-Leitbild

Ein Leitbild sagt in wenigen Sätzen, wofür das Controlling da ist. Dieses hier ist in einem Workshop des CV entstanden, aus einer Zukunftsvision und aus fünf Perspektiven, für deren Verständnis Du keine betriebswirtschaftliche Vorbildung brauchst.

Jede Lektion passt auf einen Bildschirm, wobei sich alles, was sich öffnen lässt, durch Antippen öffnet, damit das Modul auf einem Tablet genauso funktioniert wie am Rechner.

Die Leitfrage im Workshop lautete, wie das Controlling in einer vollendeten Zukunft wahrgenommen worden sein möchte, wobei die neun Antworten hier so stehen, wie sie auf den Zetteln der Runde notiert wurden.

Neun Antworten aus dem Workshop

Tipp einen Zettel an, dann erscheint darunter der Satz aus dem Workshop samt einer kurzen Erläuterung.

Die Vision in einem Satz

Aus den neun Zetteln ist im Workshop eine gemeinsame Fassung entstanden, die den Anspruch in zwei Sätzen zusammenfasst.

Die Zukunftsvision

Mit einem neu ausgerichteten Controlling, das Entscheidungen zugrunde liegt und Technik klug nutzt, gestaltet der CV seine Zukunft trotz komplexer gesellschaftlicher Entwicklungen positiv. So bleibt die wichtige Arbeit am Menschen möglich.

Die Pointe

Ein Leitbild beschreibt eine Richtung. Die Zettel sagen, woran der CV eines Tages merken wird, dass er angekommen ist.

Das Controlling wirkt entlang von fünf Perspektiven, von denen jede im Workshop eigene Stichworte bekommen hat, aus denen am Ende ein Leitsatz entstanden ist.

Fünf Perspektiven, fünf Leitsätze

Tipp eine Perspektive an, dann siehst Du darunter ihre Stichworte und ihren Leitsatz.

Die Pointe

Fünf Perspektiven genügen, weil jede von ihnen eine andere Frage beantwortet. Fehlt eine davon, fehlt dem Leitbild eine ganze Seite.

Sechs Sätze genügen für ein Leitbild, wobei fünf davon aus den Perspektiven stammen und der sechste aus der Zukunftsvision.

Das Leitbild auf einer Seite

Der Schalter blendet die Herkunft aus, damit die sechs Sätze für sich stehen.

Warum sechs Sätze und nicht sechzehn. Ein Leitbild wirkt über das, was jemand im Kopf behält. Sechs Sätze kann sich eine Leitungsrunde merken, während sie sechzehn einmal liest und danach weglegt.

Die Pointe

Jeder dieser Sätze ist eine Zusage, die jemand einlösen muss. Deshalb steht hinter jedem eine Perspektive, in der jemand dafür verantwortlich ist.

Ein Leitbild wirkt erst, wenn jemand damit arbeitet, weshalb hier die sechs Schritte stehen, mit denen eine Leitungsrunde am Montag anfängt.

Sechs Schritte für die nächste Leitungsrunde

Zu jedem Schritt steht der Grund dahinter, weil ein Schritt ohne Grund übersprungen wird.

Keiner dieser Schritte braucht eine Auswertung. Sie brauchen eine halbe Stunde in einer Runde, die ohnehin zusammenkommt, weshalb sie sich schon nächste Woche gehen lassen.

Die Pointe

Ein Leitbild an der Wand bleibt Papier. Ein Leitbild, an dem eine Runde die eigene Arbeit misst, wird zum Werkzeug.
